Программа создаёт файл при указании прав, например :

```
./permissions 745
```
или
```
./permissions rwxr--r-x
```

Создаётся файл "dummy_file" и открывается окно где показаны права в буквенном, цифровом и битовом представлении. В программе можно показать текущие права (полезно, если выводилось сообщение о некорректном вводе прав для их изменения) и изменить права. На самом деле права у файла не меняются и при перезапуске программы выводятся настоящие права (644). При повторном вызове и указании прав у уже созданного файла просто якобы меняются права в программе.

При указании любого существующего файла выводятся его настоящие права и можно якобы их изменить в программе.

Команда на изменение прав принимает цифровой вариант(например 755) или буквенный, например:
```
u+x
go-rw
g=r,o=
a+rwx
```
