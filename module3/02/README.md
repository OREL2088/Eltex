## Структура программы

- `main.c` — проверка аргументов и запуск выбранного режима;
- `common.c` — общая работа с очередью сообщений и сигналами;
- `broker.c` — приём сообщений и их рассылка подписчикам;
- `publisher.c` — ввод и отправка сообщений с указанной темой;
- `subscriber.c` — подписка на темы и получение сообщений;
- `pubsub.h` — общие константы, структуры и объявления функций;
- `Makefile` — сборка программы.

## Запуск

Собираем программу:

```bash
make
```

В первом терминале запускается брокер:

```bash
./pubsub -b
```

В другом терминале запускается подписчик. Можно указать одну или несколько тем:

```bash
./pubsub -s news sport
```

В третьем терминале запускается издатель с одной темой:

```bash
./pubsub -p news
```

После запуска издателя можно вводить сообщения и отправлять их клавишей Enter.
Сообщение получат все подписчики указанной темы.

Издатель завершает работу при закрытии стандартного ввода (`Ctrl+D`). Подписчика можно завершить сочетанием `Ctrl+C`. 

При завершении брокера сочетанием `Ctrl+C` он отправляет сигнал всем известным издателям и подписчикам, а затем удаляет очередь сообщений.
