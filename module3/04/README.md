## Структура программы

- `producer.c` — создание IPC-ресурсов, заполнение памяти и ожидание обработки;
- `consumer.c` — поиск и обработка очередного массива;
- `common.c` — семафорные операции, сигналы и вспомогательные функции;
- `shared.h` — структуры разделяемой памяти, константы и объявления;
- `Makefile` — сборка двух исполняемых файлов.

## Сборка и запуск

```bash
make
```

Сначала в отдельном терминале запускается производитель:

```bash
./producer
```

Затем можно запустить несколько потребителей:

```bash
./consumer
```

После заполнения памяти производитель ожидает обработки всех массивов.
Потребители по очереди захватывают семафор и обрабатывают по одному массиву,
после чего ненадолго засыпают. Когда обработка закончена, потребители
отключаются, а производитель удаляет разделяемую память и семафор.

Любой процесс можно остановить сочетанием `Ctrl+C`. При остановке производителя созданные им IPC-ресурсы удаляются.
