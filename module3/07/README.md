## Сборка и запуск

```bash
make
./server [PORT]
```

В других терминалах:

```bash
./client vm1 [HOST [PORT]]
./client vm2 [HOST [PORT]]
```

Значения по умолчанию: `HOST=127.0.0.1`, `PORT=5000`.

Обычная строка отправляется как сообщение. Команды клиента:

```text
/file PATH   отправить файл всем участникам
/quit        выйти
```

Полученные файлы сохраняются в текущем каталоге под именем
`received_ИМЯ_ОТПРАВИТЕЛЯ_ИМЯ_ФАЙЛА`. Существующий файл не перезаписывается:
к новому имени добавляется числовой суффикс.

Имена пользователей должны быть уникальными
