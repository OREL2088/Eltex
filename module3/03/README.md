## Структура программы

- `main.c` — проверка аргументов и запуск чата;
- `common.c` — создание, подключение и удаление очередей, обработка сигналов;
- `sender.c` — чтение строк из стандартного ввода и отправка сообщений;
- `chat.c` — приём сообщений и завершение обмена;
- `chat.h` — общие константы, структуры и объявления функций;
- `Makefile` — сборка программы.

## Запуск

В первом терминале:

```bash
./chat my_chat
```

В другом терминале необходимо запустить программу с тем же именем:

```bash
./chat my_chat
```

После подключения можно вводить сообщения и отправлять их клавишей Enter.

Завершить работу можно сочетанием `Ctrl+C` или закрытием стандартного ввода
(`Ctrl+D`). Вторая сторона получит уведомление о завершении и также закончит
работу.
