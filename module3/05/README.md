## Структура программы

- `producer.c` — создание POSIX IPC-объектов, заполнение памяти и ожидание;
- `consumer.c` — подключение к объектам и обработка очередного массива;
- `common.c` — операции с семафором, сигналы и вспомогательные функции;
- `shared.h` — структуры общей памяти, имена объектов и объявления;
- `Makefile` — сборка двух исполняемых файлов.

Сначала в отдельном терминале запускается производитель:

```bash
./producer
```

Затем запускается один или несколько потребителей:

```bash
./consumer
```

После обработки всех массивов процессы завершаются, а производитель вызывает
`shm_unlink` и `sem_unlink`. Любой процесс можно остановить сочетанием
`Ctrl+C`; при штатной обработке сигнала производитель также удаляет созданные
им именованные IPC-объекты.
