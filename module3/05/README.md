# Производитель и потребители (POSIX IPC)

Программа выполняет задание 4 с использованием POSIX IPC. Производитель
записывает в разделяемую память односвязный список массивов случайных чисел.
Один или несколько потребителей находят минимум и максимум каждого массива и
помечают его обработанным.

Разделяемая память создаётся функцией `shm_open`, получает размер через
`ftruncate` и подключается к процессам с помощью `mmap`. Доступ к списку
защищён именованным POSIX-семафором, созданным функцией `sem_open`.

Вместо указателей узлы списка содержат смещения относительно начала общей
памяти: адрес отображения `mmap` в разных процессах может отличаться.

## Структура программы

- `producer.c` — создание POSIX IPC-объектов, заполнение памяти и ожидание;
- `consumer.c` — подключение к объектам и обработка очередного массива;
- `common.c` — операции с семафором, сигналы и вспомогательные функции;
- `shared.h` — структуры общей памяти, имена объектов и объявления;
- `Makefile` — сборка двух исполняемых файлов.

## Сборка и запуск

```bash
make
```

Сначала в отдельном терминале запускается производитель:

```bash
./producer
```

Затем запускается один или несколько потребителей:

```bash
./consumer
```

После обработки всех массивов процессы завершаются, а производитель вызывает
`shm_unlink` и `sem_unlink`. Любой процесс можно остановить сочетанием
`Ctrl+C`; при штатной обработке сигнала производитель также удаляет созданные
им именованные IPC-объекты.
