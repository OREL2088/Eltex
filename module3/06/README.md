# Групповой чат через UDP broadcast

Каждый экземпляр `chat` является равноправным участником: он принимает UDP-
датаграммы на общем порту и отправляет сообщения на широковещательный IPv4-
адрес. При запуске передаётся сообщение `JOIN`, при штатном завершении —
`LEAVE`, а введённые строки передаются как `CHAT`.

В пакет входят сигнатура и версия протокола, тип сообщения, уникальный
идентификатор запущенного клиента, имя и текст. Идентификатор позволяет не
показывать клиенту его собственные широковещательные сообщения.

## Сборка

```bash
make
```

## Запуск

```bash
./chat NAME [BROADCAST_ADDRESS [PORT]]
```

По умолчанию используются адрес `255.255.255.255` и порт `5000`. Например,
два клиента в одной сети можно запустить так:

```bash
./chat alice 192.168.1.255 5000
./chat bob   192.168.1.255 5000
```

Узнать широковещательный адрес интерфейса в Linux можно командой `ip addr` —
он указан после слова `brd`. Для проверки нескольких клиентов на одной Linux-
машине можно использовать loopback broadcast:

```bash
./chat alice 127.255.255.255 5000
./chat bob   127.255.255.255 5000
```

Все участники должны использовать одинаковые адрес назначения и порт. В
виртуальных машинах сетевые адаптеры должны находиться в одной виртуальной
сети с поддержкой broadcast; межсетевой экран должен разрешать входящие UDP-
датаграммы на выбранный порт.

Завершение по `Ctrl+C` или `Ctrl+D` отправляет уведомление об уходе. UDP не
гарантирует доставку, порядок или отсутствие дубликатов, что является
свойством выбранного в задании транспорта.
